Why Terminal King Terminal?

Built for developers who want secure, instant SSH access from anywhere.

🔒

Authenticated Access

HTTP Basic Auth at the proxy layer ensures only authorized users reach the terminal. No public connection forms.

🚫

No Root Login

Root SSH is blocked by default. Uses a non-root, sudo-capable account following security best practices.

🌐

WebSocket over HTTPS

Terminal I/O flows through secure WebSocket connections. TLS terminates at the reverse proxy with auto-renewing Let's Encrypt certs.

🐳

Dockerized & Isolated

Runs in a read-only container with dropped capabilities, no-new-privileges, and an internal-only Docker network.

📋

IP Allowlist

Target hosts are restricted to an approved list. No connecting to arbitrary internet hosts.

🔑

SSH Key Support

Prefer key-based authentication over passwords. Integrates with your existing SSH key infrastructure.

How It Works

From browser to SSH server in three steps.

1

Authenticate

Your browser connects over HTTPS. The reverse proxy validates your credentials before any traffic reaches the terminal app.

2

WebSocket Upgrade

The connection upgrades to a secure WebSocket. Terminal keystrokes flow in real-time through the proxy to the backend.

3

SSH Session

The backend opens an SSH connection to the configured target host using a non-root service account. You get a full terminal session.
